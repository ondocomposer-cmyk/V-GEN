## О проекте

**V-GEN** — автоматизированный сервис для региональных телеканалов, медиахолдингов и пресс-служб, объединяющий возможности искусственного интеллекта (**Google Gemini API**) и профессионального вещательного видеомонтажа (**FFmpeg**).

### Ключевые возможности:
1. **Живой сбор новостей без жестких рамок:**
   - Поиск в реальном времени через **Google Gemini Grounding with Google Search** за последние 7–10 дней.
   - Динамический поиск по открытым городским и районным пабликам ВКонтакте и новостным порталам.
2. **Интеллектуальная редактура и рерайт:**
   - Настраиваемый в веб-интерфейсе **редакционный промпт**.
   - Автоматическое отсеивание объявлений, потерь и бытового спама.
   - Форматирование текста строго до **1000 знаков с пробелами** для диктора новостника (~45–60 секунд эфирного хронометража).
   - Числительные и даты словами («седьмого октября», «тридцать миллионов рублей»).
   - Сухой информационный стиль без лишних приветствий («здравствуйте») и штампов.
3. **Официальный синтез речи Gemini Flash TTS:**
   - Голос телевизионного диктора: **Callirrhoe** (энергичный, теплый голос) по умолчанию.
   - Возможность выбора любого из официальных дикторов Gemini (*Puck, Charon, Kore, Fenrir, Aoede, Leda, Orpheus, Zephyr*).
   - Озвучивается строго чистый текст новости из поля без посторонних указаний модели.
4. **Умный видеоряд и эффекты:**
   - Автоматический подбор фото и адаптация к Full HD 1080p методом **Smart UNCROP**.
   - Плавный кинематографичный **эффект Кена Бернса** (Zoom In / Zoom Out) со субпиксельным скейлом без дрожания (jitter).
   - **Мульти-папки B-Roll («КОНСЕРВЫ»):** указание нескольких директорий с нарезками видео видов города/дронов, переключение между ними и сквозной поиск.
   - **Выбор фоновой музыки:** настройка нескольких путей/треков в админке с предпрослушиванием и выбор индивидуального трека (или тишины) для каждого сюжета.
   - Эфирная отбивка канала с автоматической нормализацией SAR (1:1), FPS (30) и звука.
   - Точный расчет хронометража слайдов: пауза 1.0 сек до голоса, 3.0 сек финал, синхронный **Fade Out 1.5 сек**.
   - Наложение полупрозрачного эфирного логотипа телеканала в безопасной зоне кадра.
5. **Экспорт видео с русскими именами файлов:**
   - Готовый видеоролик скачивается под именем заголовка новости на русском языке (например: `Ремонт теплосетей в Тутаеве.mp4`).

## Пошаговая инструкция быстрого запуска (за 5 минут)

Сервис оптимизирован для работы на **Windows 10 / 11** (а также запускается на Linux и macOS).

### Шаг 1. Создание папки и открытие командной строки через адресную строку

1. Откройте **«Этот компьютер»** или **Проводник** (сочетание клавиш `Win + E`).
2. Перейдите на любой удобный локальный диск (например, `C:\`, `D:\` или `F:\`).
3. Создайте новую папку для проекта, например с названием **`V-GEN`** или **`новостник`**, и зайдите внутрь неё.
4. **Удобный способ открыть консоль:**
   - Кликните левой кнопкой мыши по **адресной строке Проводника** вверху (где отображается текущий путь к папке).
   - Весь путь выделится синим цветом — сотрите его и наберите с клавиатуры: **`cmd`**
   - Нажмите клавишу **Enter**.
   - *Сразу откроется черное окно командной строки Windows (`cmd.exe`), уже расположенное строго внутри вашей созданной папки!*

---

### Шаг 2. Скачивание (клонирование) репозитория

В открывшемся черном окне командной строки выполните команду:

```bash
git clone https://github.com/ondocomposer-cmyk/V-GEN.git .
```

> **Обратите внимание:** точка в конце команды (` .`) указывает Git склонировать все файлы проекта напрямую в текущую открытую вами папку без создания лишних вложенных директорий.  
> *(Если вы клонируете без точки: `git clone https://github.com/ondocomposer-cmyk/V-GEN.git`, после завершения обязательно перейдите внутрь папки: `cd V-GEN`)*.

---

### Шаг 3. Установка зависимостей Python

Убедитесь, что на компьютере установлен **Python 3.10** или новее *(при установке Python не забудьте отметить галочку «Add Python to PATH»)*, а также установлен **FFmpeg** (должен быть доступен в PATH).

В этом же окне командной строки установите библиотеки проекта:

```bash
pip install -r requirements.txt
```

*(Установятся необходимые модули: `fastapi`, `uvicorn`, `google-genai`, `httpx`, `pillow`, `feedparser`, `beautifulsoup4`, `jinja2` и др.)*

---

### Шаг 4. Получение бесплатного API-ключа Gemini

1. Откройте сайт [Google AI Studio (API Keys)](https://aistudio.google.com/apikey).
2. Нажмите синюю кнопку **Create API key** (создается бесплатно за 15 секунд, банковская карта не требуется).
3. Скопируйте полученный ключ вида `AIzaSy...`.

---

### Шаг 5. Запуск сервиса

В окне командной строки запустите сервис:

```bash
python run.py
```

В консоли появится баннер запуска:
```
======================================================================
   V-GEN — АВТОМАТИЧЕСКАЯ ГЕНЕРАЦИЯ ВИДЕОНОВОСТЕЙ ДЛЯ ТВ
   Автор скрипта: Дмитрий Асанов (@sandefiord, asanov@lux.tv.ru)
======================================================================
Веб-интерфейс доступен по адресам:
  -> Главная (Новости и генерация): http://localhost:8000
  -> Админ-панель (Настройки V-GEN): http://localhost:8000/admin
  -> Архив видеороликов:           http://localhost:8000/archive
======================================================================
```

---

### Шаг 6. Первичная настройка и генерация видео в браузере

1. Откройте браузер по адресу: **`http://localhost:8000/admin`** (вкладка **«Админ-панель»**).
2. Вставьте ваш `Gemini API Key` в поле и нажмите **«Проверить»** — система подтвердит успешную связь с нейросетью.
3. Проверьте переключатель **«Поиск Google в реальном времени (Grounding)»** (должен быть включен).
4. Настройте пути к видеоархиву B-Roll и трекам фоновой музыки (можно добавить несколько путей).
5. При необходимости загрузите свой PNG-логотип телеканала и отбивку.
6. Нажмите кнопку **«СОХРАНИТЬ ВСЕ НАСТРОЙКИ»**.
7. Перейдите на главную страницу **`http://localhost:8000`** и нажмите **«Собрать и обработать новости за 7 дней»**.

Через 20–30 секунд готова полная сетка сюжетов с текстами, таймингами и Full HD видеороликами MP4!
