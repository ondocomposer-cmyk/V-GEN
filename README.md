## О проекте

**V-GEN** — автоматизированный сервис для региональных телеканалов, медиахолдингов и пресс-служб, объединяющий возможности искусственного интеллекта (**Google Gemini API**) и профессионального вещательного видеомонтажа (**FFmpeg**).

### Ключевые возможности:
1. **Живой сбор новостей без жестких рамок:**
   - Поиск в реальном времени через **Google Gemini Grounding with Google Search** за последние 7–10 дней.
   - Динамический поиск по открытым городским и районным пабликам ВКонтакте и новостным порталам.
2. **Интеллектуальная редактура и рерайт:**
   - Настраиваемый в веб-интерфейсе **редакционный промпт**.
   - Автоматическое отсеивание объявлений, потерь и бытового спама.
   - Форматирование текста строго до **1000 знаков с пробелами** для диктора новостника (~45–60 секунд эфирного хронометража).
   - Числительные и даты словами («седьмого октября», «тридцать миллионов рублей»).
   - Сухой информационный стиль без лишних приветствий («здравствуйте») и штампов.
3. **Официальный синтез речи Gemini Flash TTS:**
   - Голос телевизионного диктора: **Callirrhoe** (энергичный, теплый голос) по умолчанию.
   - Возможность выбора любого из официальных дикторов Gemini (*Puck, Charon, Kore, Fenrir, Aoede, Leda, Orpheus, Zephyr*).
   - Озвучивается строго чистый текст новости из поля без посторонних указаний модели.
4. **Умный видеоряд и эффекты:**
   - Автоматический подбор фото и адаптация к Full HD 1080p методом **Smart UNCROP**.
   - Плавный кинематографичный **эффект Кена Бернса** (Zoom In / Zoom Out) со субпиксельным скейлом без дрожания (jitter).
   - **Мульти-папки B-Roll («КОНСЕРВЫ»):** указание нескольких директорий с нарезками видео видов города/дронов, переключение между ними и сквозной поиск.
   - **Выбор фоновой музыки:** настройка нескольких путей/треков в админке с предпрослушиванием и выбор индивидуального трека (или тишины) для каждого сюжета.
   - Эфирная отбивка канала с автоматической нормализацией SAR (1:1), FPS (30) и звука.
   - Точный расчет хронометража слайдов: пауза 1.0 сек до голоса, 3.0 сек финал, синхронный **Fade Out 1.5 сек**.
   - Наложение полупрозрачного эфирного логотипа телеканала в безопасной зоне кадра.
5. **Экспорт видео с русскими именами файлов:**
   - Готовый видеоролик скачивается под именем заголовка новости на русском языке (например: `Ремонт теплосетей в Тутаеве.mp4`).

## Быстрый запуск

### 1. Клонирование
```bash
git clone https://github.com/ondocomposer-cmyk/V-GEN.git
cd V-GEN
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Убедитесь, что у вас установлен Python 3.10+ и FFmpeg доступен в PATH)*

### 3. Запуск
```bash
python run.py
```

После старта веб-интерфейс доступен в браузере:
- **Эфирная лента новостей:** [http://localhost:8000](http://localhost:8000)
- **Панель управления (Настройки V-GEN):** [http://localhost:8000/admin](http://localhost:8000/admin)
- **Архив готовых видеороликов:** [http://localhost:8000/archive](http://localhost:8000/archive)
